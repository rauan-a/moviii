# Наши фильмы (простая версия)

Список фильмов, которые вы посмотрели вместе: счётчик, вкладка «Хотим посмотреть», кнопка «Случайный фильм». Без постеров, без пароля, без TMDB.

Стек: Next.js 14 + Supabase (база) + Vercel (хостинг).

## 1. Supabase

1. Создай проект на https://supabase.com.
2. В **SQL Editor** выполни содержимое `supabase/schema.sql` (если таблица `movies` уже есть, повторять не нужно).
3. В **Project Settings → API** скопируй `Project URL` и ключ `service_role`.

## 2. Vercel

1. Загрузи проект в GitHub и импортируй его на https://vercel.com.
2. В **Environment Variables** добавь две переменные:

| Имя | Значение |
| --- | --- |
| `SUPABASE_URL` | Project URL из Supabase |
| `SUPABASE_SERVICE_ROLE_KEY` | ключ service_role |

3. Нажми **Deploy**. После любого изменения переменных делай **Redeploy**.

Если что-то не сохраняется, сайт покажет текст ошибки прямо в окне.

## Чтобы данные не пропали

- Удаление «мягкое»: фильм скрывается, но остаётся в базе. Вернуть: `update movies set deleted_at = null where id = 123;`
- `vercel.json` раз в сутки обращается к сайту, чтобы бесплатная база Supabase не «засыпала».
- Пароля нет: ссылку на сайт лучше никому не отправлять.
